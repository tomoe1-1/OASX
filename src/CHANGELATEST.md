# v2.2.0

## 新增 | Feature
- 统计页重做为可交互 Dashboard：模块网格支持拖动排序，顺序写入本地存储且不影响工作台栏宽
- 模块原位放大，底部缩略条切换模块，关闭后恢复原模块位置与滚动位置
- 顶部常驻全局筛选（日期、指标、排序），统计数字滚动过渡、图表平滑更新，日期请求期间保留上一次数据并显示进度
- 图表悬停联动：三个图表同步高亮同一任务，其余任务淡化并显示竖向参考线
- 指标汇总区滚动吸顶，向下连续收缩为单行固定栏，反向滚动连续还原
- 任务列表详情抽屉：右侧滑出执行详情，列表缩窄并保持可见，使用上下按钮切换任务

## 修复 | Fix
- 日期快速切换时校验请求版本并停止旧流，避免旧响应覆盖新选择
- 派生任务缓存同时校验快照身份，总运行时间不变时任务次数更新不再漏掉

## 验证 | Verification
- 新增 9 项 Dashboard 交互测试（拖拽、放大、联动、吸顶、抽屉、320/480/760 窄窗口）与 3 项统计控制器测试
- 本机手工测试链（frontend_server + flutter_tester）跑通全部 21 个测试文件，163 项通过
- 修改文件 Dart 静态分析无问题

- Windows 版本 2.2.0+25
