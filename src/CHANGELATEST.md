# v2.4.0

## 新增 | Feature
- 主页背景的少女会缓慢睁眼：18 秒一轮，0.7 秒静止后 3.6 秒睁开、保持 12.5 秒、1.2 秒闭合
- 启动页少女同步睁眼；任务模式下 controller 只驱动眼睑，进度仍由外部任务驱动
- 眼睑是**真正的眼皮在动**：5 张预渲染姿态图按眼睑高度做单调 Hermite 插值，再用网格变形把带睫毛的眼皮条带移到目标高度，周围头发皮肤保持不动
- 系统开启「减少动态效果」时停在睁开状态并保持静止，内容正确、只去掉运动

## 修复 | Fix
- 启动页任务模式下 controller 不启动，眼睛会一直闭到进度走完；改为 controller 独立驱动眼睑
- 启动页收尾计时不再按固定停留，改为「剩余动画时长 + 停留」；任务已失败时不再空等剩余时长
- 启动页「半睁」姿态图与「四分之一睁」几乎相同，会让眼睑在半途停住；显式跳过这张重复图

## 验证 | Verification
- 新增 11 项眼睛动画回归：眼睑高度连续性（逐 0.01 秒扫描无跳变）、姿态图资源登记、主页睁眼时间线、启动页睁眼与真实素材渲染、版本号三处来源一致
- 本机手工测试链（frontend_server + flutter_tester）跑通 26 个测试文件中的 24 个，共 170 项通过
- 另有 2 项为**仓库既有失败**（`args_test` 的 multi_enum 解析、Flutter 模板残留的 `widget_test`），与 2.1.0 / 2.2.0 / 2.3.0 基线对照失败方式一致，与本次改动无关
- 资源清单 `AssetManifest.bin` 已登记 pubspec 声明的全部 21 条资源，并新增 7 条眼睑姿态图

## 版本 | Version
- Windows 版本 2.4.0+27

# v2.3.0

## 新增 | Feature
- 失败任务行复用工作台任务操作栏，可直接「立即执行 / 等待顺延 / 打开参数」，无需切回任务列表
- 操作栏在 260 / 360 / 700 px 窄窗口下不溢出；任务被手动禁用、批量快捷调度进行中或已有其他任务运行时，快捷按钮自动置灰并保留参数入口

## 修复 | Fix
- 快捷调度写入「下次执行时间」时，联动配置此前沿用外层脚本名与任务名，导致写错任务或状态判断错误；改为下发各自解析后的脚本与任务名
- 任一联动配置下发失败时如实向上返回失败，不再误报成功

## 验证 | Verification
- 新增 35 项失败任务操作回归：三按钮路由与窄窗口自适应、按钮可用性联动、联动配置逐一下发与失败传播
- 本机手工测试链（frontend_server + flutter_tester）跑通全部 21 个测试文件，165 项通过
- 修改文件 Dart 静态分析无问题

## 版本 | Version
- Windows 版本 2.3.0+26
