# OASX 2.1.0 失败任务选择

本版修复失败任务在重试队列期间从工作台任务选择列表消失的问题，版本为 2.1.0+24。

## 行为变化

- 工作台任务选择列表把失败任务队列中**仍处于启用状态**的任务一并纳入，
  任务失败进入重试队列后不再从可选列表消失。
- 失败任务被手动禁用后不再被自动重新纳入选择；任务重新入队时恢复可选中状态。
- 当前任务、待执行队列与等待队列的选择逻辑保持不变。

## 验证

新增 33 项任务选择回归，覆盖「失败入队 → 保持可选 → 手动禁用 → 重新入队」的状态流转；
前端 32 项、后端 67 项既有回归继续通过。

## 安装

完整解压运行目录，保留同级 data、DLL 和 src 文件夹后双击 oasx.exe。
本版保留 2.0.3 的全幅动态背景、跨栏缩放与标题栏修复。
默认 OAS 私库仍为 tomoe1-1/OAS-tomoe 的 self 分支，已有有效自定义目录继续使用。
