# OASX 2.3.0 失败任务操作

本版给失败任务行补齐与普通任务一致的快捷操作，并修复联动配置下快捷调度写错任务的问题，版本为 2.3.0+26。

## 行为变化

- 失败任务队列中的每一行现在复用工作台任务行同一套操作栏，可直接完成
  **立即执行**、**等待顺延**（刷新「下次重试时间」）与**打开参数**，不必切回任务列表。
- 操作栏在 260 / 360 / 700 px 宽窗口下均不溢出，图标按钮始终可见。
- 以下情况快捷按钮自动置灰，仅保留参数入口：
  - 该失败任务被手动禁用；
  - 批量快捷调度（全部立即执行 / 全部等待）进行中；
  - 已有其他任务处于运行状态。
- 失败任务行以任务名建立稳定键，重试时间随队列变化即时刷新。

## 修复

- 快捷调度写「下次执行时间」时，**每个联动配置**此前沿用外层传入的脚本名与任务名，
  导致联动配置写错任务或状态判断错误；现改为向每个配置下发各自解析后的脚本与任务名。
- 任一联动配置下发失败时如实向上返回失败，不再误报成功。

## 验证

新增 35 项失败任务操作回归，覆盖三按钮路由、窄窗口自适应、按钮可用性联动，
以及联动配置逐一下发与失败传播；本机手工测试链（`frontend_server` + `flutter_tester`）
跑通全部 21 个测试文件，共 **165 项通过**。

## 安装

完整解压运行目录，保留同级 `data`、DLL 和 `src` 文件夹后双击 `oasx.exe`。
本版保留 2.2.0 的可交互 Dashboard 与 2.1.0 的失败任务选择行为。
默认 OAS 私库仍为 `tomoe1-1/OAS-tomoe` 的 `self` 分支，已有有效自定义目录继续使用。
