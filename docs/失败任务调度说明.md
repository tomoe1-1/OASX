OASX 左侧任务概览增加独立的“失败任务”区域，显示任务名和下次重试时间。

- 失败记录保存在 OAS 的 `log/task_failed/<配置名>.json`，与正常排队和等待队列分开，重启后保留。
- 任务失败后按该任务的“失败间隔”计算下次重试时间。同一任务重复失败只更新原记录。
- 每次调度先选择已到期的正常排队任务；没有正常排队任务时，才执行已到重试时间的失败任务。
- 显示的重试时间是最早可重试时间。如果正常任务仍在排队，实际重试会延后。已经开始执行的任务不会被强行中断。
- 重试成功后自动清除失败记录，任务恢复正常调度。
- 任务被停用后，失败记录仍显示，并提示“已停用，重试暂停”，不会自动执行。
- 旧版本已有的失败检查点和 Restart 恢复等待会自动迁移；GotoMain 使用 Restart 的失败间隔。

验证：67 项后端调度/失败处理测试及 32 项前端同步/布局测试通过，已构建 Windows release。
