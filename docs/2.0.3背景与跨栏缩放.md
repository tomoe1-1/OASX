# OASX 2.0.3 背景与跨栏缩放

版本：2.0.3+23。

## 外观

- 标题栏与正文共用一个全幅动态背景，顶部使用 32% 不透明度的白色圆角框，保留头像、设置、拖动和窗口操作。
- 浅色主题主面板、右侧工作台、内部日志卡片的不透明度分别降为 50%、38%、44%；深色主题分别为 64%、50%、58%。
- 背景从第一帧开始保留相同组件树，资源加载不再替换正文的父级结构；出血绘制裁剪到当前窗口范围内。
- 配置面板由同一个 Material 表面绘制底色和开关点击反馈，避免半透明装饰层遮住反馈。

## 跨栏缩放

用户在 2.0.2 中确认三栏缩到一、两栏再拉回三栏，仍可能出现右侧旧画面或透明残框。异常时读取到 Windows 主客户区与 Flutter 子窗口的尺寸一致，上一版的原生尺寸校正不足以证明画面问题已消除。

实际工作台回归发现另一项确定的问题：内部栏宽拖动尚未完成时，外部缩窗移除分隔条，临时拖动比例可能在重新展开后继续生效。新版在约束变化和手势取消时清除临时拖动值及折叠预览，重新按保存的栏宽、当前可用宽度计算布局。

保留 2.0.2 的原生尺寸同步和不透明窗口底色。软件背景、标题框、工作台的透明效果均在应用内部合成。

## 验证范围

针对真实工作台的日志、统计、任务参数页面反复执行三栏→两栏→单栏→两栏→三栏；另外覆盖左右分隔条拖动被缩窗中断、指针取消及背景宽窄切换。

这些测试覆盖组件尺寸、状态与绘制边界。2026-10-01，用户从 `C:\Users\12296\Desktop\yys\OASX-2.0.3` 启动新版后，实际执行“三栏缩到一、两栏，再放回三栏”，确认缩放已正常，右侧透明残框不再出现。此实机结果对应本电脑。
