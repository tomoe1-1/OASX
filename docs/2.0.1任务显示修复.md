# OASX 2.0.1 任务显示修复

本版修复左侧配置卡把下一个任务误显示为当前任务的问题，版本为 2.0.1+21。

## 显示规则

- 当前任务：取调度器运行日志确认的实际任务；停止后显示“暂无运行任务”。
- 下个任务：按后端调度顺序显示待执行队列首项；没有待执行任务时显示等待队列首项及运行时间。
- 两行同时显示，长名称省略，悬停可以查看完整内容。窄面板仍保留两行。
- 中途连接会回溯近期日志恢复当前任务。日志接口不支持或近期日志找不到任务边界时，显示“正在获取”，等待实时任务日志确认。

## 安装

完整解压运行目录，保留同级 data、DLL 和 src 文件夹后双击 oasx.exe。
本版保留 2.0.0 的窗口位置恢复、有效 OAS 目录识别、动态背景与启动画面修复。
默认 OAS 私库仍为 tomoe1-1/OAS-tomoe 的 self 分支，已有有效自定义目录继续使用。

## 后续版本

每次修复补丁版本递增 0.0.1，构建号同步递增。src 包含完整源码，tools 包含构建辅助工具。
