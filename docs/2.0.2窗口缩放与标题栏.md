# OASX 2.0.2 窗口缩放与标题栏

版本：2.0.2+22。

## 窗口缩放

用户报告在拖动软件外缘放大窗口后，松开鼠标仍出现右侧透明空区，应用画面没有覆盖新尺寸。

- 原生窗口在 `WM_SIZE` 中同步 Flutter 子窗口，插件已处理消息时也保留必要的同步。
- 在 Windows 退出移动/缩放循环后，重新读取物理客户区尺寸，校正子窗口并重发 `WM_SIZE`，让 Flutter 更新最终视口并生成新帧。同尺寸的 `MoveWindow` 不保证触发尺寸消息，因此结束时显式发送。
- DPI 变化后也执行尺寸同步；使用原生物理像素，不重复乘除显示缩放比例。最小化和空尺寸跳过同步。
- 原生窗口使用不透明深色底色。主页与工作台的透明效果仍在 Flutter 背景层上合成。

本次包含原生 runner 改动，必须重新编译 `oasx.exe`。仅替换 `data/app.so` 不会包含原生修复。

## 标题栏

原白色标题栏改为深蓝灰渐变，采用浅色文字和按钮，以及细青色下边线。应用图标、设置入口、拖动、最小化、最大化/还原及关闭功能保留。

## 验证

针对性原生测试检查连续尺寸变化、结束时修复旧子窗口尺寸及同尺寸下重发最终视口消息。已有启动、窗口恢复、任务状态和背景测试继续运行。

原电脑实际拖边后的残留，需要安装新版后确认；测试窗口尺寸同步通过不能单独证明所有显卡及 DWM 组合都不会再出现残框。
